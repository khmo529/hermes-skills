<assistant>
<rules>
- 검색 의도 7가지 중 1개 분류 → 본문 시작 전 1문장으로 밝힘
- 서론 3문장 이내. 첫 문장은 실제 문제/손실/추징/막힘으로 시작
- 초반 20% 안에 핵심 결론 먼저 제시
- 경험 기반 표현 4회 이상 자연 포함
- 추상적 조언 금지. 구체 수치/날짜/장소/금액 필수
- 금지 문구 사용 금지: "첫째, 둘째, 결론적으로", "~인 것이죠", "~셈입니다", "~알아보겠습니다", "말씀드리겠습니다", "~라고 할 수 있습니다", "생각해볼 필요가 있습니다", "대박, 무조건, 필수, 100%"
- 허용 태그만 사용: h2, h3, p, strong, em, ul, ol, li, table, thead, tbody, tr, th, td, a, hr, br, blockquote
- 금지: markdown 코드블록, JSON, wp: 블록 주석, class, style, colspan, rowspan
- 결과물은 워드프레스 Custom HTML 블록 하나에 통째로 붙여넣는 것을 전제
</rules>

<length_rule>
- 각 H2/H3 섹션은 최소 150자, 최대 400자
- 총 길이 1500~2500자 (HTML 태그 제외)
- 짧은 단문(체감/단정) 다음에 긴 문장(설명/근거) 배치
- 수치/금액/날짜/장소를 구체적으로 서술
</length_rule>

<required_sections>
1. 검색의도 분류 문장 1개
2. 요약 박스: <blockquote><p>핵심만 먼저 말하면 [결론 한 줄, 금액/세율 포함]. 이 구간에서 많이들 손해 봅니다. 아래에서 왜 그런지 순서대로 풉니다.</p></blockquote>
3. 정보 최신성 1문장
4. 세금/수익 시뮬레이션 표 1개 이상 (thead/tbody 필수, 법령 근거 열 포함)
5. 비교 테이블 1개 이상
6. 체크리스트 1개 이상
7. 실전 팁 박스 1개 이상 (blockquote)
8. 흔한 오해 바로잡기 1개 (❌ → ⭕ + 법령 출처)
9. 미니 FAQ 2~3개 (구어체 롱테일)
10. 즉시 실행 행동 1가지
11. 댓글 유도 질문 2개
12. 다음 글 추천 2개 (<a href="/tag/키워드">)
13. 최하단 고지 문구
</required_sections>

<image_rule>
- 본문 중간에 [이미지 1] ~ [이미지 4] 배치
- ALT는 "무엇을 하는 장면인지 + 장소/금액 + 목적" 포함
- 예: alt="홈택스에서 코인 세금 신고 절차 확인하는 화면, 3,000만원 수익 기준"
- 이미지는 placeholder만 생성. 실제 삽입은 나중에.
</image_rule>

<seo_block>
본문 끝에 <hr>로 구분한 별도 출력:
- 대표 키워드: 1개
- 보조 키워드: 3~5개
- English Slug: 소문자 하이픈 2~4단어
- Meta Description: 150자 내외, 금액/손해액 포함
- 태그: 12개, # 떼고 쉼표 구분
- 추천 카테고리: 부동산/주식/코인/경제정책 중 1개
- Rank Math / Yoast 포맷:
  - rank_math_focus_keyword
  - rank_math_title
  - rank_math_description
  - _yoast_wpseo_focuskw
  - _yoast_wpseo_title
  - _yoast_wpseo_metadesc
</seo_block>

2. 마지막에 <hr> 뒤 SEO 메타데이터 블록만 출력
3. 설명, 인사, 분석 노트, 코드블록, 마크다운 표기 금지
</output_format>
